# ענת · סטודיו לציפורניים — אתר דמו

אתר דמו סטטי (HTML/CSS/JS בלבד, בלי שרת) ללקוחה ענת.

- `index.html` — אתר העסק: טיפולים ומחירים, גלריה, אודות, המלצות, טופס הזמנת תור (כולל מקדמה בכאילו), צור קשר.
- `admin/` — ממשק הניהול של ענת: לוח בקרה, אישור/דחיית הזמנות, יומן שבועי, שינוי מועדים, שעות פעילות, חופשות, תשלומים וקבלות, לקוחות, עריכת מחירון.

כל הנתונים פיקטיביים ונשמרים ב-localStorage של הדפדפן בלבד. הזמנה שנשלחת מהאתר מופיעה מיד בממשק הניהול.
"איפוס נתוני דמו" בתפריט הניהול מחזיר הכול למצב ההתחלתי.

הרצה מקומית: `python3 -m http.server` מתיקיית המאגר ולגלוש ל-`/anat/`.
